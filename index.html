Data → Image

PixPack

Encode any text, URL, Wi-Fi credentials, image or binary file into PNG images — and decode them back perfectly.

  • Pixel PNG, Color Grid & QR formats
  • Wi-Fi QR (WPA / WPA2 / WPA3)
  • Parallel compression (CMX1, Brotli, Zstd…)
  • Web UI + CLI
Demo GitHub
Proxy

SocksHttpGate

SOCKS5 and HTTP/S proxy on a single port, with standalone DoH, DoT and ODoH services. Multiple language implementations.

  • SOCKS5 + HTTP on one port
  • DoH · DoT · ODoH
  • Python, Go, C, Node, Java…
  • Auth & dashboard
GitHub
Visual

goR

Lightweight API that generates animated text GIFs with 17 digital-distortion and retro effects. Perfect for banners and Discord.

  • 17 effects (glitch, VHS, RGB, type…)
  • Built-in + custom fonts
  • Transparent background & seed
  • Cache + CORS ready
Demo GitHub
Android

Tunnel

Run Cloudflare Tunnel (cloudflared) on your Android phone. Expose a local service with a token or a temporary quick URL, and keep it alive in the background.

  • Quick (try) & Token modes
  • Foreground service + auto-restart
  • Encrypted token, saved settings
  • ARM64 · ARMv7 · x86_64 APKs
